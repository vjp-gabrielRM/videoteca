# Videoteca

## Qué hace la aplicación

Mantiene un catálogo de películas y series. La página muestra sus tarjetas y
estadísticas, y permite buscar, ordenar y añadir elementos. El orden elegido se
guarda en una cookie.

## Trabajo en pareja

Grupo 4: Gabriel Ruz Macias y Daniel Iglesias Ramos.


## Datos de cada elemento

Cada elemento tiene un ID y seis campos: título, género, fecha de lanzamiento,
sinopsis, tipo y duración en minutos. El catálogo contiene ocho elementos

## Qué se ha hecho en el Sprint 0

 Se creó el catálogo y se muestra con console.table.
 Se añadieron listados, filtros por año y recuentos por tipo.
 Se implementaron las funciones para listar, buscar, añadir y eliminar.
 Se añadieron estadísticas de duración total, media y elemento más largo.

## Cómo se ejecuta

Abre `index.html` con Live Server en VS Code; no lo abras con doble clic porque
la aplicación usa módulos de JavaScript. La página muestra el catálogo y sus
estadísticas, y permite buscar, ordenar y añadir elementos.
