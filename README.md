# Videoteca

## Qué hace la aplicación

Mantiene un catálogo de películas y series. Muestra los datos en la consola del
navegador y permite listar, buscar, añadir y eliminar elementos, filtrar por año,
contar por tipo y consultar estadísticas de duración.

## Datos de cada elemento

Cada elemento tiene un ID y seis campos: título, género, fecha de lanzamiento,
sinopsis, tipo y duración en minutos. El catálogo contiene ocho elementos

## Qué se ha hecho en el Sprint 0

 Se creó el catálogo y se muestra con console.table.
 Se añadieron listados, filtros por año y recuentos por tipo.
 Se implementaron las funciones para listar, buscar, añadir y eliminar.
 Se añadieron estadísticas de duración total, media y elemento más largo.

## Cómo se ejecuta

Abre index.html en un navegador y consulta la consola del navegador. Las
funciones también se pueden llamar desde esa consola.
