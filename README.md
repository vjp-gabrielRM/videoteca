# Videoteca

- **Tema:** Videoteca.
- **Colección:** series y películas.
- **Campos:** ID, título, género, fecha de lanzamiento, sinopsis y tipo (serie o película).
- **Grupo:** En pareja (Grupo 4).
- **Nombre de la aplicación:** Videoteca.

## Qué hará la aplicación

La aplicación mantiene un catálogo de series y películas con sus datos principales.
Muestra la colección en una tabla y permite consultar un listado con una etiqueta según el año de lanzamiento.
